# Primary full-run DCM exports

`DCM_A_allsubjects_wide.csv` contains the participant-level A-matrix estimates used for the reported primary full-run analysis. It comprises 360 model rows (45 participants × 2 runs × ALL/Block-01/Block-02/Block-03) and the 16 A-matrix parameters.

`DCM_group_edge_summary.csv` contains group descriptive summaries derived from the participant-level export.

The DCM specification used TE = 0.05 s (50 ms).
