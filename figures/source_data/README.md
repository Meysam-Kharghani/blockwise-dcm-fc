# Figure source data

The files in this directory provide tabular inputs for the publication-oriented figures and associated QC summaries.

Key files include:

- `primary_fullrun_DCM_A_allsubjects_wide.csv` — participant-level primary A-matrix export.
- `dcm_edge_contrasts.csv` — run-averaged DCM block contrasts.
- `peb_bma_all_effects.csv` — PEB/BMA effects.
- `dcm_model_fit_group_summary.csv` — model-fit summaries.
- `dcm_posterior_prevalence_by_run.csv` — posterior-prevalence summaries.
- `Figure_5_transformed_self_connections.csv` — transformed self-connection values used in the model-behavior figure.
- `raw_fc_edge_summary.csv` and `residual_fc_edge_summary.csv` — FC summaries.
- `LateEffect_ModelFit_Association.csv` — participant-level association between the mean Late effect across the six strongest descriptive DCM edges and Block-03 model fit.
- `Participant_CrossEdge_Consistency.csv` and `Participant_StrongEdge_Heterogeneity.csv` — participant-level directional-consistency summaries.
