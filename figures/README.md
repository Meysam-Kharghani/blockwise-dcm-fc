# Figures and source data

`main/` contains the six manuscript main figures. `supplementary/` contains additional run-, edge-, node-, participant-, PEB-, FC-, and model-behavior visualizations. Supplementary file names are descriptive rather than tied to a specific manuscript numbering scheme.

`source_data/` contains the principal tabular inputs used for figure construction, including participant-level A-matrix estimates, edge contrasts, PEB/BMA summaries, model-fit data, posterior-prevalence summaries, self-connection summaries, FC summaries, participant-level directional-consistency tables, and the association between the mean strong-edge Late effect and Block-03 model fit.

Main and supplementary figures are provided in PNG and PDF formats.
